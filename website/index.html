Every GPU in the room, one training run.

GradApp finds the other computers on your Wi-Fi, gives each one a slice of your dataset sized to its GPU, and averages what they learn into one model. NVIDIA, Intel Arc and Apple Silicon, side by side.

Download GradApp Free, for Windows, macOS and Linux Other platforms

Three steps, no terminal

  1. One computer hosts

    Open GradApp and press Host a mesh. It sets up the coordinator, downloads the base YOLO models and installs PyTorch in its own folder.

  2. Everyone else presses Join

    GradApp on the other machines finds the mesh on the same network, detects the GPU, installs the matching PyTorch build and runs a test kernel before joining.

  3. Train together

    Upload a YOLO dataset, start a run, and watch each machine take its shard. Download the averaged weights when it finishes.

Closing the window keeps GradApp running quietly in the tray, so a machine can lend its GPU overnight and stop with one click.

What each machine needs

NVIDIA GTX 900 series or newer on Windows or Linux, driver 580 or newer (RTX 50 series: 570).
Intel Arc A or B series, or Core Ultra with Arc graphics, on Windows or Linux with a current driver.
Apple M1 or later on macOS 14 Sonoma or newer.
Every machine Python 3.10 to 3.13. On Windows GradApp installs it for you; on a Mac, brew install python@3.12.

A computer without a supported GPU can still host the mesh. AMD GPUs and Intel Macs cannot train yet.

Questions

Does my data leave the network?

No. The dataset stays on the host, each machine fetches only the images in its shard, and training runs with telemetry and update checks switched off. The only internet traffic is the one-time download of PyTorch and the base models.

Is it safe to join a stranger's mesh?

Join meshes on networks you trust. A mesh is protected by a token that anyone on the same network can read from the host, and the host's code runs on your GPU. GradApp is built for a lab, a dorm or a home network, not a coffee shop.

How much faster is training?

It depends on how many machines join and how big the dataset is, because every round has a fixed cost per machine. In GradMesh's own measurements two machines reached 1.5× on 1000 images and about 1.1× on 100. The Runs screen shows the measured speed-up for each run.

What does it install, and how do I remove it?

Everything goes into two folders: ~/.gradmesh/agent for the contributor's PyTorch, and GradApp's own data folder (Settings shows it). Uninstall the app and delete those folders to remove all of it.

Windows asked whether Python may use the network.

Choose Allow for private networks. The host's coordinator listens on ports 8000 and 3000 so other machines can reach it; without the exception they cannot join. On a public network, do not host.

I already use GradMesh from the terminal.

GradApp speaks the same protocol. It can join a mesh started with npm run dev, attaches to a coordinator already running on the same computer, and a GradApp host still serves the irm … | iex and curl … | sh join commands.
