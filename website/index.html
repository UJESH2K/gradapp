Built around the GPU you have

CUDA

GTX 900 series or newer, on Windows or Linux. Driver 580 or newer (RTX 50 series: 570). GradApp picks the CUDA 12.6, 12.8 or 13.0 build that matches your driver.

XPU

Arc A or B series, or Core Ultra with Arc graphics, on Windows or Linux with a current Intel driver. Same PyTorch version as everyone else, so weights average cleanly.

Metal

M1 or later on macOS 14 Sonoma or newer. An 8 GB MacBook Air is enough to take a shard. Intel Macs cannot train yet.

Made to stay out of the way

Finds the mesh itself

No IP addresses to read off a screen. GradApp looks on your network and shows the meshes it finds.

Fair shards

Each machine's speed and fixed overhead are learned round by round, so a fast desktop and a slow laptop finish together.

Quiet in the tray

Close the window and it keeps contributing. Open at login, start hidden, rejoin the last mesh: all optional.

Joinable without the app

A GradApp host still serves the one-line join commands, so a lab PC can lend its GPU from a terminal.

Your data stays in the room

The dataset lives on the host. Each machine fetches only the images in its shard, training runs with telemetry and update checks switched off, and nothing goes to a cloud. The only internet traffic is the one-time download of PyTorch and the base models.

A mesh is protected by a token that anyone on the network can read from the host. Use it on networks you trust: a lab, a dorm, your home.

Questions, answered

Do I need Python?

Yes, 3.10 to 3.13. On Windows GradApp installs Python 3.12 for you with one click. On a Mac run brew install python@3.12; on Linux use your package manager. Everything else installs into GradApp's own folders.

Does my data leave the network?

No. The dataset stays on the host and each machine fetches only the images in its shard. Training runs with telemetry and update checks switched off.

How much faster is training?

It depends on how many machines join and how big the dataset is. In GradMesh's measurements two machines reached 1.53× on 1,000 images and about 1.1× on 100. The Runs screen shows the measured speed-up for every run.

Is it safe to join someone else's mesh?

Join meshes on networks you trust. The host's training code runs on your GPU, and the mesh token can be read by anyone on the same network. Rotating the token on the host disconnects every machine.

What does it install, and how do I remove it?

Two folders: ~/.gradmesh/agent for the contributor's PyTorch, and GradApp's data folder (Settings shows it). Uninstall the app and delete both to remove everything.

I already use GradMesh from the terminal.

GradApp speaks the same protocol. It joins meshes started with npm run dev, attaches to a coordinator already running on the same computer, and a GradApp host still serves the irm … | iex and curl … | sh join commands.
